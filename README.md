# Поздравление для Альберта v9 polished

Это откат на старую структуру, но с новым аккуратным дизайном по макету.

Внутри:
- index.html
- style.css
- script.js
- assets/profile.png
- assets/final.png
- assets/memories.jpg
- assets/group_cat.png
- assets/success_cat.png
- assets/error_cat.png
- assets/happy_birthday.mp3

Что сделано:
- дизайн в стиле японский cyber-anime / sakura neon;
- использованы готовые картинки из макета, без генерации новых;
- музыка подключена;
- 10+ человек в поиске окружения;
- 100% вместо MAX;
- в секретном файле только одна кнопка;
- финальное поздравление показывает финальную картинку и текст пожелания ниже;
- фото воспоминаний можно приближать пальцами.

GitHub Pages:
1. Загрузи все файлы из архива в корень репозитория.
2. Settings -> Pages -> Deploy from a branch -> main -> /root.
3. После обновления открой ссылку с ?v=9, чтобы сбросить кеш.
