# Поздравление для Альберта

Мини-приложение для iPhone, Telegram Web App и GitHub Pages.

## Как запустить через GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в него все файлы из этой папки:
   - index.html
   - style.css
   - script.js
   - папку assets
3. Открой Settings.
4. Перейди в Pages.
5. В Source выбери Deploy from a branch.
6. Branch: main.
7. Folder: /root.
8. Сохрани.
9. Через 1-3 минуты GitHub выдаст ссылку на сайт.

## Как отправить в Telegram

Можно просто отправить ссылку с GitHub Pages.

Для Telegram-бота сделай кнопку Web App с этой ссылкой.
