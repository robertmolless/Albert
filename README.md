## Как залить на GitHub Pages

1. Загрузи все файлы из архива в корень репозитория.
2. Открой Settings.
3. Перейди в Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /root.
7. Сохрани.
