## Важно про iPhone

iPhone не разрешает запускать музыку автоматически без действия пользователя.
Поэтому музыка стартует после первого нажатия на кнопку "Начать диагностику" или отдельной кнопки "Музыка: включить".

## Если хочешь закинуть музыку сам

Положи mp3 по пути:

assets/happy_birthday.mp3

В index.html уже прописано:

<audio id="birthdayMusic" src="assets/happy_birthday.mp3" preload="auto" loop playsinline></audio>

## GitHub Pages

Загрузи все файлы из архива в корень репозитория и включи Pages:
Settings -> Pages -> Deploy from a branch -> main -> /root.
